Controls & Keybinds
Key	Function
W	Move forward (HUD display)
A	Move left (HUD display)
S	Move backward (HUD display)
D	Move right (HUD display)
SPACE	Jump (HUD display)
Q	Toggle LMB Auto Clicker
E	Toggle LMB Hold
R	Toggle RMB Auto Clicker
F	Toggle RMB Hold
↑	Toggle Auto-W
←	Toggle Auto-A
↓	Toggle Auto-S
→	Toggle Auto-D
0	Toggle Auto-Jump
X	Reset HUD and reload page
ALT + S	Save game controls

🖱️ HUD Interaction
Action	Function
ALT + Left Click + Drag	Move HUD
ALT + Right Click + Drag	Resize HUD
Mouse movement	3D HUD tilt effect
ALT	Enter HUD interaction mode

📊 HUD Features
- 3D Keyboard Display – Real-time WASD and SPACE visualization.
- Mouse Activity Monitor – LMB/RMB activity and CPS counter.
- Live Graphs – Visualize key and mouse activity.
- Auto Clicker – Automated LMB and RMB clicking.
- Hold Mode – Maintains simulated mouse button presses.
- Auto Movement – Repeated keyboard events for WASD.
- Auto Jump – Repeated SPACE key events.
- Particle Effects – Sparks, shockwaves and click animations.
- Position Memory – Remembers HUD position and scale.
- Control Backup – Saves game-related local storage settings.

An advanced 3D interactive HUD for Bloxd.io featuring live input visualization, activity graphs, auto-clicking, hold controls, automated movement, and customizable positioning. 🚀
